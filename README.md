# Python-for-AI
A practical learning repository covering Python fundamentals and AI-focused programming. It includes hands-on examples, exercises, and mini-projects to build a strong foundation for Generative AI, Machine Learning, and Agentic AI.

## Topics Covered

- Python Basics & OOP
- Functions, Modules & Packages
- Data Structures
- File & API Handling
- NumPy & Pandas
- AI/ML Fundamentals
- LLM & Generative AI Integration
- AI Agents & Automation
